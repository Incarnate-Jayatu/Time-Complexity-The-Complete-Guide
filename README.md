# 🚀 Big-O Cheat Sheet

| Input Size | Recommended Complexity |
|------------|-----------------------|
| `n ≤ 10` | `O(n!)`, `O(2ⁿ)` |
| `n ≤ 20` | `O(2ⁿ)` |
| `n ≤ 500` | `O(n³)` |
| `n ≤ 2,000` | `O(n²)` |
| `n ≤ 100,000` | `O(n log n)` |
| `n ≤ 10⁷` | `O(n)` |
| Very Large | `O(log n)` or `O(1)` |
